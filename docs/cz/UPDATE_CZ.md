# Aktualizace Lístečků

[Česky](UPDATE_CZ.md) · [English](../en/UPDATE.md) · [Dokumentace](../cz/README_CZ.md)

Zálohuj společně databázi Nextcloudu a kód aplikace, aktualizuj a zapni Shared App Core 0.18.0-dev.2+ a pak v rozbaleném **zdrojovém** ZIPu spusť `sudo sh install.sh`. Skript používá PHP pomocné soubory v `scripts/`, zachovává původní data a žádný import nespouští. Úplný postup a kontrolu účtů, úloh a prohlížeče obsahují [instalace](../cz/INSTALL_CZ.md) a [kontrola NC35](../cz/NC35_REVIEW_CZ.md). `build-release.sh` sestavuje nový runtime ZIP v `release/` pro správce projektu; pro instalaci staženého zdrojového balíku potřeba není.

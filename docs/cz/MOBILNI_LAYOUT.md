# Lístečky: mobilní rozložení

Verze: 2.0.11. Aplikace používá Layout API Shared App Core na Nextcloudu 35.

Nástěnka má jednu hlavní posuvnou oblast Core. Na telefonu se filtry kategorií, stavů, řazení a hledání otevřou tlačítkem **Filtry**. Po výběru kategorie nebo stavu se nabídka zavře a hlavní část obrazovky zůstává pro lístečky. Editor a nastavení se posouvají uvnitř dialogu, který reaguje na otevřenou klávesnici.

## Kontrola na telefonu

Přibližte nástěnku, posuňte ji do stran a otevřete dlouhý lísteček i nastavení. Ve formuláři otevřete klávesnici a ověřte dosažitelnost tlačítka Uložit.

# Categories and appearance

[English](CATEGORIES.md) | [Česky](CATEGORIES_CZ.md) | [← Documentation](README.md)

Categories organize sticky notes and provide visual distinction.

## Personal categories

Personal categories are intended for organizing a user's own notes.

## System categories

Sticky Notes also supports system categories intended for shared use and administration by administrators.

## Category appearance

Categories can have:

- a name,
- color,
- icon,
- custom visual style.

The category style is reflected in the final appearance of its notes.

## Natural sticky-note appearance

The application can optionally use a more natural presentation with slight note tilt and shadows instead of a perfectly aligned grid.

## Readability

Text contrast is automatically adjusted according to the note background to preserve readability across different color combinations.

See [Application settings](SETTINGS.md) for global display options.

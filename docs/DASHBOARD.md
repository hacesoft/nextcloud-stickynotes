# Dashboard widget

[English](DASHBOARD.md) | [Česky](DASHBOARD_CZ.md) | [← Documentation](README.md)

Sticky Notes includes a widget for the Nextcloud Dashboard.

## Purpose

The widget provides a compact view of sticky notes without opening the full application and is intended for quick access to important items.

## Number of notes

The widget layout can be configured by column and row count, which determines how many notes can fit into the available space.

## Ordering

Pinned notes are intended to represent the most important items, followed by additional notes as space permits.

## New note

The widget provides an action for creating a new sticky note.

## Appearance

Widget notes use a more compact presentation than the main application while retaining their visual identity and category.

Widget layout options are described in [Application settings](SETTINGS.md).

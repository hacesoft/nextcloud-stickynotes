## What is Sticky Notes?

Sticky Notes is a Nextcloud application for quick notes and lightweight personal, family, or team tasks. Notes can be colored, organized into categories, assigned to users or groups, and marked as completed.

## Main screen

The top area contains note statistics and controls for filtering, sorting, pagination, and search. Sticky notes are displayed on the application's workspace.

Views are available for all notes, the user's own notes, notes assigned to the current user, shared notes, and completed notes.

## Creating a note

The **New note** button opens the editor. A note can contain content, a category, type, priority, due date, and optionally a user or group assignment.

The editor supports formatted titles and note bodies. See [Note editor](../en/EDITOR.md).

## Categories

Categories organize notes and provide visual distinction. Sticky Notes supports personal and system categories with icons and custom styles.

See [Categories and appearance](../en/CATEGORIES.md).

## Tasks

A sticky note can be used as a lightweight task with a priority and due date and can be marked as completed. Active and completed items can be filtered.

## Pinning and ordering

Important notes can be pinned. Manual note ordering is also supported.

## Search and filters

For larger collections, use search, filters, sorting, and pagination. Category filters provide quick access to related notes.

## Sharing and assignment

Notes can be assigned to individual Nextcloud users or groups. See [Sharing, assignment, and notifications](../en/SHARING.md).

## Dashboard

Sticky Notes includes a Dashboard widget for seeing important notes without opening the full application. See [Dashboard widget](../en/DASHBOARD.md).

## Desktop, tablet, and mobile

The interface is responsive and intended for desktop, tablet, and mobile use. The editor and dialogs adapt to the available screen space.

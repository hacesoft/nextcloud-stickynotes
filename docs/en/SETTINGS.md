# Application settings

[English](SETTINGS.md) | [Česky](../cz/SETTINGS_CZ.md) | [← Documentation](../en/README.md)

Application settings are opened with the **gear** button. Category/style management remains separate from normal application settings.

## Widget settings

The number of widget columns and rows can be configured. These values determine the maximum layout of Sticky Notes in the Dashboard widget.

## Pagination and layout

Users can configure notes per page and workspace width. Version 2.0.9 contains a full responsive pass for the main page, filters, pagination, settings, categories, and dialogs. On narrow phones the note board switches to a single column and controls are constrained to the viewport.

Verify the responsive layout on the target phone, tablet, and desktop before publishing the NC35 release.

## Notifications

Notification preferences are per user. Each user can independently enable built-in Nextcloud notifications and optional ntfy delivery. ntfy supports a custom server URL, topic, optional access token, and a **Send test notification** action.

Selectable events include direct assignment, group assignment, sharing, task completion/reopening, and deadline notifications at 24 hours, 1 hour, and due-now. See [Notifications](../en/NOTIFICATIONS.md).

## Sticky note appearance

Optional natural tilt and shadows are available. Categories can define their own colors, icons and marker styles. See [Categories and appearance](../en/CATEGORIES.md).

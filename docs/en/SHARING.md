# Sharing, assignment, and notifications

[English](SHARING.md) | [Česky](../cz/SHARING_CZ.md) | [← Documentation](../en/README.md)

Sticky Notes uses Nextcloud users, groups, and its notification system.

## User assignment

The editor can select up to 32 users or groups for one note or task. Each selection is shown as a removable chip. Every assignee may edit the item and receive notifications. Existing single assignments remain intact; additional targets use the existing shares table with the `assign` permission.

## Group assignment

A note can also be assigned to a group, which is useful for lightweight family or team tasks.

## Shared and assigned notes

The main screen provides dedicated filters for assigned and shared items so they can be separated from the user's own notes.

## Completing a task

Tasks can be marked as completed, and completed items can be viewed separately.

## Notifications

The application supports assignment notifications. Application settings control whether assignment notifications are used.

## Privacy

Normal operation does not require an external cloud service. Sticky Notes uses Nextcloud's local database, users, groups, and notification system.

# Changelog

## 1.0.0

First stable release.

- Sticky notes and tasks with priority and due dates.
- Rich-text editor with formatting, lists, links and tables.
- Personal and system categories with custom visual styles.
- User and group assignment and sharing.
- Nextcloud notifications for task assignment.
- Pinning, drag-and-drop ordering, search, filters, sorting and pagination.
- Dashboard widget with configurable layout.
- Automatic text contrast for different note backgrounds.
- Responsive desktop, tablet and mobile user interface.
- Optional persistent note tilt and shadow.
- Multiple UI languages.
